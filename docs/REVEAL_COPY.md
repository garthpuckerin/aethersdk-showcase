## Title

AetherSDK — The seams between systems, made visible

## Short description

An interactive operations cockpit showing how connector validation, governed
sync, identity links, audit, webhook recovery, metering, health, and access
control can read as one cohesive system.

## Case-study summary

Working features are not enough when each screen tells a different story. This
showcase starts from stable tenant, request, run, entity, event, delivery, and
payload identities, then carries them through two inspectable workflows. Retry
changes one failed target without duplicating a successful link. Delivery
exhaustion creates a traceable dead letter; replay resolves it and updates audit,
health, and usage projections. Desktop governance and a focused mobile
companion use the same fictional state graph and permission policy.
